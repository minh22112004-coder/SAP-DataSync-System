SAP DATASYNC — HƯỚNG DẪN VẬN HÀNH VÀ BÀN GIAO
Phiên bản: 1.1.1 — SQL Server 2022 cài trực tiếp trên Windows

1. YÊU CẦU MÁY TRIỂN KHAI

- Windows x64 phù hợp với SQL Server 2022.
- Microsoft SQL Server 2022 đã cài trực tiếp trên Windows.
- Default instance MSSQLSERVER, Mixed Mode, TCP/IP port 1433.
- Docker và Docker Compose để chạy Web API cùng ETL Worker; database không chạy trong Docker.
- SQL Server Management Studio (SSMS) nếu người vận hành cần giao diện quản trị database.
- Khuyến nghị tối thiểu 8 GB RAM, trình duyệt hiện đại và dung lượng đĩa phù hợp dữ liệu.

2. CẤU HÌNH SQL SERVER

File .env dùng các giá trị SQL_HOST, SQL_PORT, SQL_DATABASE, SQL_USER và SQL_PASSWORD.
Container dùng SQL_HOST=host.docker.internal để truy cập SQL Server trên Windows host.
Không dùng localhost trong connection string của container.

Kỹ thuật viên kiểm tra trước bằng:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\test-external-sqlserver.ps1

Script phải xác nhận SQL Server major version 16, Mixed Mode, đăng nhập hợp lệ và quyền tạo
database. Không gửi file .env hoặc ghi mật khẩu vào command line/log.

3. CÀI ĐẶT VÀ KHỞI ĐỘNG

1) Chạy SapDataSync-Setup-1.1.1.exe.
2) Mở SAP DataSync từ Start Menu hoặc shortcut Desktop.
3) Launcher tạo .env từ .env.example nếu chưa tồn tại và không tự đổi mật khẩu SQL Server.
4) Bấm “Khởi động hệ thống”. Launcher kiểm tra SQL Server trước khi chạy Web API/ETL.
5) Khi SQL Server, Web API và ETL Worker báo sẵn sàng, bấm “Mở Web App”.
6) Web App mặc định mở tại http://localhost:8080.

Nút “Dừng hệ thống” chỉ dừng Web API và ETL Worker. SQL Server service trên Windows không bị
dừng và database SapDataSync vẫn được giữ nguyên.

4. THIẾT LẬP QUẢN TRỊ LẦN ĐẦU

1) Web App chuyển tới trang “Cài đặt” nếu chưa có quản trị viên.
2) Tạo mật khẩu tối thiểu 12 ký tự, có chữ hoa, chữ thường, số và ký tự đặc biệt.
3) Ghi mật khẩu vào trình quản lý mật khẩu được tổ chức phê duyệt.
4) Chỉ quản trị viên đã đăng nhập mới có thể upload Excel, import hoặc thay đổi API key.

5. ĐƯA FILE EXCEL VÀO HỆ THỐNG

Cách khuyến nghị: đăng nhập quản trị, mở “Lịch sử import”, chọn file .xlsx rồi bấm
“Upload & Import”. Hệ thống kiểm tra định dạng, SHA-256, tạo snapshot và ghi ImportLog.

Cách dùng thư mục nguồn: sao chép file export*.xlsx vào data\source rồi bấm “Chạy import ngay”.
Không chép file đang được SAP ghi dở.

6. XEM LOG VÀ XỬ LÝ LỖI

  docker compose ps -a
  docker compose logs --tail 200 web-api
  docker compose logs --tail 200 etl-worker
  docker compose logs --since 30m

Nếu SQL Server không sẵn sàng, kiểm tra Windows service MSSQLSERVER, TCP/IP, port 1433,
Mixed Mode, firewall và tài khoản trong .env. Launcher không start/stop SQL Server service.

7. BACKUP VÀ RESTORE

  powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\backup-database.ps1

Script kết nối trực tiếp SQL Server host, tạo COPY_ONLY BACKUP WITH CHECKSUM trong thư mục
backup mặc định của SQL Server và chạy RESTORE VERIFYONLY. Xem hướng dẫn restore riêng tại
docs\HUONG_DAN_RESTORE_SQLSERVER.txt. Không tự động restore hoặc ghi đè production.

8. DỪNG VÀ GỠ CÀI ĐẶT

- “Dừng hệ thống” chỉ chạy docker compose stop cho Web API và ETL Worker.
- Trước khi gỡ cài đặt, tạo backup database.
- Uninstaller không xóa SQL Server, database, Docker volume, .env, backup hoặc file Excel.

9. CHECKLIST BÀN GIAO KỸ THUẬT

[ ] SQL Server 2022 native, Mixed Mode và TCP 1433 hoạt động.
[ ] Preflight SQL Server thành công.
[ ] Launcher chỉ quản lý Web API/ETL và hiển thị đúng trạng thái database.
[ ] Upload/import file mẫu thành công và ImportLog đúng.
[ ] Database còn nguyên sau khi dừng/khởi động lại ứng dụng.
[ ] Backup và RESTORE VERIFYONLY thành công.
[ ] Edition SQL Server và license phù hợp với môi trường sử dụng.
[ ] Mật khẩu SQL thật không nằm trong Git, log hoặc tài liệu bàn giao chung.
